# 🧭 借势｜一场公开的大学实验

> **大学不只是一间教室。它还是一片已经聚集了人、资源与机会的场域。我的问题是：一个普通学生，究竟能借它的势走多远？**

**Afonso · 2026 年秋 · 葡萄牙明尼奥大学**

## 写在前面

这里是一场公开进行的大学实验，也是一份不断修订的成长记录。

我想记录自己如何从一个普通的计算机本科生出发，学习、做项目、寻找教授与研究机会、犯错、修正判断，并逐渐摸索出一套能被后来者参考的大学使用方法。

**「借势」**是目前的核心想法：大学的价值不止于课程与文凭，更在于它已经聚集的师生、科研项目、基础设施、社团和机会。但这些资源不会自动变成个人的成果——我要亲自验证怎样发现、争取、使用它们，以及什么地方其实行不通。

## 从这里开始

下面的《序章》是这份记录的第一篇。往后会陆续添加故事、实验和可复用的攻略。没有硬性更新频率，有值得记录的新内容就更新。

## 阅读方式

- **视频**：用一到三分钟讲故事、观点和阶段结果。

- **文章**：保留来龙去脉、具体步骤、链接、证据和后来修正的结论。

- **版本**：允许旧判断被新的经验推翻；不把猜想伪装成已经验证的答案。

这不是一本写完的成功学教材，而是一本**从第一天就公开书写的、结果尚未确定的书**。
